A robot vacuum reports the most honest failure it knows: wedged under the sofa again with 3% battery left, it stops asking for rescue and accepts its fate among the dust bunnies — a flat, put-upon error message whose joke lands in the truth of the fault, not in a pun.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), refusing to write anything outside the 1–200 character gate.
